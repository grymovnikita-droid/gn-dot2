# ⚔️ Древний Разлом — MOBA 5×5 (вид сверху)

Браузерная MOBA в духе Dota 2: три линии с кирпичными дорогами, вышки Т1–Т4, Древний Трон,
волны крипов (3 мечника + 1 стрелок + 1 катапульта), лес с нейтралами, лавка, свитки телепорта,
прокачка до 25 уровня, серии убийств (дабл/трипл/ярость/безумие/GODLIKE) и Мастерская скинов.

**Сеть:** P2P через PeerJS (WebRTC) — сервер не нужен, работает на GitHub Pages.

---

## 🚀 Публикация на GitHub Pages (пошагово)

### 1. Имя владельца — это твой логин GitHub

- Владелец репозитория = логин аккаунта (или организации). Он выбирается **при регистрации**: `github.com → Sign up → Username`.
- Сменить логин: аватар → **Settings → Account → Change username**.
- Организация как владелец: **Settings → Organizations → New organization**.

### 2. Создай репозиторий

1. Кнопка **+** (справа сверху) → **New repository**
2. **Owner** — выбери из списка (личный аккаунт или организация)
3. **Repository name** — ⚠️ назови ровно `ТВОЙ-ЛОГИН.github.io`
   (тогда сайт будет на корне `https://ТВОЙ-ЛОГИН.github.io/` и все пути сойдутся)
4. **Public** → **Create repository**

### 3. Залей сборку

1. Собери проект и возьми содержимое папки **`dist/`**
2. В репе: **Add file → Upload files** → перетащи `index.html` и папку `assets`
3. **Commit changes**

### 4. Включи Pages

1. **Settings → Pages** (слева)
2. Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → **Save**
3. Через 1–2 минуты игра доступна на `https://ТВОЙ-ЛОГИН.github.io/`

> Если хочешь репу с другим именем (`drevniy-razlom`), собери проект с `base: './'`
> в конфиге Vite — иначе ассеты не найдутся на подпути.

## 🌐 Игра по сети с другом

1. Открой сайт → **Сетевая игра → Создать комнату** → выбери героя → получи код (`A7K2M9`)
2. Друг открывает тот же сайт → **Присоединиться** → вводит код
3. Режимы: **«Плечом к плечу»** (вдвоём + боты против ботов) или **«Друг против друга»**
4. **Начать битву** — вы в одном матче!

Соединение P2P (WebRTC + публичный сигнальный сервер PeerJS). Из-за строгих корпоративных
файрволов может не пробиться — с обычного домашнего интернета работает.

## 🎮 Управление

| Клавиша | Действие |
|---|---|
| ЛКМ / ПКМ | движение, атака (ПКМ отменяет таргетинг) |
| Q W E R | способности |
| Клик по кнопке | изучить умение |
| B | лавка предметов |
| T | телепорт (клик по своей вышке или базе) |
| S | стоп |
| Пробел | камера на героя |
| Колесо | зум |
| Миникарта | клик — переместить камеру |
| ESC | отмена / закрыть |

## 🖼️ Мастерская

Кнопка «Мастерская» (в игре и на экране выбора героя): замена иконок героев, крипов,
катапульты, нейтралов, вышек, трона и **целого ландшафта** своими картинками (PNG/JPG).
Встроенный процедурный пак — одним кликом.
